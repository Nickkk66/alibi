Installation & Setup

Install Alibi on macOS

Alibi is a single app in a disk image. Three steps and it is in your Applications folder.

  1. Download Alibi.dmg and open it from your Downloads folder.

  2. Drag the Alibi icon into the Applications folder shown next to it.

  3. Open Alibi from Applications. The first time, right-click it and choose Open, then confirm. Alibi is signed but not notarized with Apple, so macOS asks once.

Why right-click?Notarization needs a paid Apple developer account. Alibi is free, so instead of paying Apple to vouch for it you can read the source and build it yourself. After the first Open, it launches like any other app.
