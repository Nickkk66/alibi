Introduction

FAQ

Short answers. The guides go deeper.

Is it safe?

Alibi uses the same location-simulation service Xcode uses when a developer tests a maps app. It runs on your Mac, it does not modify the phone, and pressing Reset puts real GPS back instantly.

Which apps see the new location?

All of them. The fix is injected below the app layer, so Maps, Find My, games, dating and delivery apps all read the simulated position.

What happens when I unplug?

If you press Reset first, the phone is back on real GPS. If you press Lock, turn Developer Mode off on the phone and then unplug, iOS keeps the last simulated location until the phone restarts. See Keep it after unplugging.

Can it work without a cable?

Yes, with Alibi Mobile: a companion app installed from the Mac once, which then changes location on the phone by itself. Plug in once a week so the Mac can re-sign it.

Why does the app ask for a code?

Alibi needs an access code the first time it opens. Codes look like ALIBI-7KQ2M, come with a time limit that starts when you first use them, and are checked with Alibi’s licence server, so they cannot be shared or forged. The app checks in every day and keeps working for a few days offline.

Which map styles are there?

Dark, Satellite (with place names), Matrix, and Light. The layers button on the map cycles through them, and 3D tilts any style except Satellite.

Does Alibi phone home?

No. The only network calls are to Apple (for the developer image), OpenStreetMap and OSRM (map tiles, search and road routing) and, if you choose Satellite, Esri imagery. There is no Alibi server.
