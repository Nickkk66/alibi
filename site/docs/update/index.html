Installation & Setup

Update Alibi

Alibi does not update itself and does not check for updates, because it never talks to a server it does not need to.

  1. Quit Alibi. If a location is being changed, press Reset first (or Lock, if you want the phone to keep it).

  2. Download the latest Alibi.dmg and drag the app into Applications again, replacing the old one.

  3. Open it. Your bookmarks, history, presets and settings are kept; they live in the app’s own storage, not in the app bundle.

Release notes are on the GitHub releases page. The version you have is under Settings › About.
