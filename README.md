# Alibi

Put your iPhone anywhere on Earth from your Mac. Every app believes it.

- **Website and docs:** https://nickkk66.github.io/alibi/
- **Download for Mac:** https://github.com/Nickkk66/alibi/releases/latest/download/Alibi.dmg

This repository holds the website and the release builds. The app itself needs an access code
the first time it opens; codes come with a time limit and are checked against Alibi's licence
server, so they cannot be shared or forged. Get one from the website.

The source code is not published here.

## Website

Everything under `site/` is plain HTML, CSS and JavaScript, deployed to GitHub Pages by the
workflow in `.github/workflows/pages.yml` on every push to `main`.

## Reporting a problem

Open an issue on this repository with the diagnostics from Settings › Phone › Copy diagnostics.
